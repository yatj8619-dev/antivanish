# AntiVanish (Fabric, Minecraft 1.21.1, client-side)

Build: install JDK 21, then run `./gradlew build` (generate the wrapper with `gradle wrapper` if needed).
The jar is in build/libs/. Needs Fabric Loader, Fabric API and Mod Menu in your mods folder.
Set the target player in Mod Menu -> AntiVanish -> Configure.
